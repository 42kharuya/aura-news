# User Story Map

| 活動                 | タスク                       | MVP                                                      | Next (Phase 2)                              | Later (Phase 3+)                       |
| -------------------- | ---------------------------- | -------------------------------------------------------- | ------------------------------------------- | -------------------------------------- |
| **初期設定**         | アプリを開き、設定を済ませる | 興味のあるカテゴリを選ぶ（最大3つ程度）                  | カテゴリの自由な並び替えや追加追加          | 任意のキーワードを登録して購読する     |
| **情報取得（閲覧）** | 厳選されたニュースを見る     | 「朝刊」「昼刊」「夕刊」のニュース一覧（要約付き）を見る | 過去の配信分（昨日の朝刊など）を振り返る    | プッシュ通知を見てアプリを開く         |
| **情報取得（詳細）** | 気になる記事を深く知る       | 要約からオリジナル記事（Webブラウザ）へ遷移する          | 「保存」した記事の一覧画面を見る            | オフライン状態でも保存記事を読む       |
| **フィードバック**   | 自分の好みを反映させる       | 記事に「保存」「興味なし」をつける                       | フィードバックが翌日の配信に反映される      | 自分の閲覧傾向の分析レポートを見る     |
| **完了**             | 読み終えた達成感を得る       | ニュースを最後まで見ると「完了」画面が出る               | 完了時にSNSへ「今日の振り返り」をシェアする | 連続完了記録（ストリーク）が表示される |

---

**MVP 境界:**
「カテゴリ選択」「定時配信（リスト表示と完了画面）」と「要約・選定理由の閲覧」「簡易フィードバック（ボタンを押すだけ）」までを実装し、それ以外（パーソナライズの高度な反映、過去記事閲覧、プッシュ通知、シェア）はNext以降とする。
